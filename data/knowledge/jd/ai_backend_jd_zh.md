# AI 应用开发工程师（后端方向）- 岗位说明书

## 岗位信息

- 岗位名称：AI 应用开发工程师（大模型后端方向）
- 所属部门：智能平台研发部
- 工作地点：杭州 / 远程可选
- 经验要求：3 年以上后端开发经验，1 年以上大模型应用开发经验
- 学历要求：本科及以上，计算机相关专业优先

## 岗位职责

1. 负责公司大模型应用平台的后端设计与开发，包括 RAG 知识库、Agent 工作流、模型网关等核心系统。
2. 设计并持续优化检索增强生成管线：文档解析与切块、Embedding、混合检索、Rerank、上下文管理，持续提升回答准确率与忠实度。
3. 基于 LangGraph 等框架编排多步 Agent，实现工具调用、人机协同、状态持久化与失败恢复。
4. 构建模型与 RAG 系统的离线/在线评测体系，用数据驱动 prompt、检索策略与模型选型决策。
5. 保障服务在高并发场景下的性能与稳定性：缓存、异步化、限流降级、容量评估与全链路可观测。
6. 与算法、前端、产品团队协作，推动大模型能力在客服、营销、研发提效等业务场景落地。

## 任职要求

### 必备要求

1. 扎实的 Python 工程能力，熟悉 FastAPI 或同等异步 Web 框架，理解事件循环、协程与并发控制。
2. 深入理解 RAG 全链路，有混合检索（向量 + 关键词）、Rerank、查询改写、Chunking 策略的实战与调优经验。
3. 熟悉至少一种主流 Agent 编排框架（LangGraph/LlamaIndex/AutoGen），理解 ReAct、Plan-and-Execute、状态机等模式的适用边界。
4. 熟悉主流向量数据库（Qdrant/Milvus/Weavate 等）及其索引原理（HNSW 参数、距离度量）。
5. 扎实的后端基本功：MySQL 索引与事务、Redis 常见模式、消息队列、Docker 容器化部署。
6. 有良好的工程习惯：类型标注、单元测试、异常处理、结构化日志、代码评审。

### 加分项

- 有 RAGAS/自建 LLM-as-judge 评测体系落地经验，能讲清指标定义与评测陷阱。
- 有 Function Calling / 多 Agent 协作 / Agent 长短期记忆的生产实践。
- 熟悉 DeepSeek、通义千问等国产大模型 API 与 OpenAI 兼容协议，了解模型参数（temperature、top_p）对输出的影响。
- 有大模型应用的成本与延迟优化经验（缓存、模型分级、prompt 压缩、流式输出）。
- 有 Kubernetes、可观测（OpenTelemetry/Langfuse）实践经验。

## 我们会重点考察

- RAG 各环节失败模式的定位能力：检索不到、检索到但排得靠、上下文丢失、模型幻觉分别如何诊断与解决。
- 系统设计：设计一个支持多知识库、可溯源、可评测的企业问答系统。
- 代码能力：异步并发、幂等、重试退避、边界条件处理。
- 项目深度：能讲清所做项目的量化指标、技术选型取舍与踩坑细节，而非停留在"调用了 API"。

## 福利待遇

- 有竞争力的薪资与股票期权；MacBook Pro 等设备；
- GPU 算力额度、大模型 API 报销、技术书籍与会议预算；
- 弹性工作时间，核心工作时间 10:30 - 16:30。
